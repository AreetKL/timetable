# 课表日历

拍张课表，变成日历里的课。

自己天天要翻课表，做一个顺手的。

## 干什么的

拍照，或者从相册选一张课表，识别出来列成表给你核对。看着没问题，整份写进系统日历。

不是塞一堆日程完事。周重复、停课周跳过、调课周单独写一条，都按实际情况来。

首页只放今天：今天几节课，下一节还剩多久。底下配一句古诗，每天换。

## 一些细节

识别默认在本机跑，ML Kit 的中文模型，断网也能用。

嫌不够准可以填自己的 AI Key。走 OpenAI 兼容接口，智谱、通义、Kimi、硅基流动、OpenAI、Gemini、阶跃都认，接口地址和模型名也能自己填。不填不影响用。

学期哪天开学、一共几周、每节几点上、上午下午各几节，都能改。改完自己重排，不用重新导入。

系统日历哪天被清空了，设置里点一下重新写回去。

课表能导成一张长图，发给同学。

## 装

Releases 里下 APK。`arm64` 那个，绝大多数手机适用；老机型下 `arm32`。

最低 Android 8.0。

## 编

Android Studio 打开直接跑。命令行：

```bash
./gradlew assembleRelease
```

Kotlin + Jetpack Compose，Material 3。没有统计、没有广告、没有账号体系。除了你主动点的在线识别，不发任何请求。

release 现在挂的是 debug 签名，自己发版记得换掉，位置在 `app/build.gradle.kts`。
